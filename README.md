# ML-course-projects
Hands-on ML course projects in Python (scikit-learn, NumPy, Pandas, Matplotlib): classification, regression, and more.

| Project | Task | Models / Methods | Best result |
|---------|------|------------------|-------------|
| [Classification](classification_project/) | Heart attack risk prediction | Logistic Regression, Decision Tree, KNN, SVM | Recall 0.91 (high-risk class) |
| [Decision Tree](decision_tree_project/) | Drug type prediction from patient data | Decision Tree (entropy, max_depth=4) | Accuracy 0.83 |
| [K-Means](kmeans_project/) | Customer segmentation | K-Means, elbow method, PCA | 4 clusters |
| [KNN](knn_project/) | Student admission prediction | KNN (k=4) | Accuracy 0.87 |
| [Regression](regression_project/) | Apartment price prediction | Polynomial Ridge Regression, GridSearchCV | R² 0.72 |
